# GeoRevolt Demo Scenario

## Предварительные условия

- Anvil запущен на `localhost:8545`
- Контракты задеплоены (см. `forge script script/Deploy.s.sol:Deploy --sig "runAnvil()"`)
- Next.js запущен (`npm run dev`)
- Браузер с MetaMask (или другим EIP-1193 кошельком) подключён к `localhost:8545`
- Импортирован тестовый аккаунт: `0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`

## Сценарий

### Шаг 1: Осмотр карты
1. Откройте `http://localhost:3000`
2. Убедитесь, что карта MapLibre загрузилась (demotiles)
3. Видны маркеры рынков (зелёные точки) и кластеры (фиолетовые круги)
4. Приблизьте карту — кластеры распадаются на отдельные маркеры

**Ожидаемый результат:** Карта отображается, маркеры есть.

### Шаг 2: Подключение кошелька
1. Нажмите **Connect Wallet** в левом верхнем углу
2. В MetaMask выберите аккаунт #1 (deployer)
3. Адрес кошелька отобразится в левом верхнем углу

**Ожидаемый результат:** Кнопка сменилась на адрес и Disconnect.

### Шаг 3: Покупка YES токенов
1. Кликните на любой маркер на карте
2. В боковой панели видна информация о рынке (название, описание, статус)
3. Выберите сторону **YES** (зелёная кнопка)
4. Введите сумму: `100` (USDC с 6 decimals)
5. Нажмите **Buy YES**
6. Подтвердите две транзакции в MetaMask (approve + buy)

**Ожидаемый результат:** В секции "Your Position" появился YES баланс > 0.

### Шаг 4: Продажа YES токенов
1. В боковой панели нажмите **Sell** рядом с YES балансом
2. Подтвердите транзакцию в MetaMask

**Ожидаемый результат:** YES баланс обнулился. Можно купить снова.

### Шаг 5: Админ — разрешение рынка
1. Перейдите на `http://localhost:3000/admin`
2. Подключите кошелёк (если ещё не подключён)
3. Найдите нужный рынок в списке
4. Нажмите **Resolve YES** (или **Resolve NO**)
5. Подтвердите транзакцию в MetaMask (resolveMarket)

**Ожидаемый результат:** Статус рынка изменился на "Resolved: YES".

### Шаг 6: Получение выигрыша
1. Вернитесь на карту (`http://localhost:3000`)
2. Кликните на разрешённый рынок
3. В боковой панели отображается "Market resolved — YES won"
4. Нажмите **Redeem Winnings**
5. Подтвердите транзакцию в MetaMask

**Ожидаемый результат:** Баланс USDC в кошельке увеличился.
