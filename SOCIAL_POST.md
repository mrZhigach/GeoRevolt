# GeoRevolt — Social Media Posts

## English 🇬🇧

### Post for LinkedIn / Twitter / Telegram

🚀 **GeoRevolt v1.0.0 — Decentralized Prediction Markets on an Interactive Map** 🗺️

GeoRevolt is an open-source platform that combines AMM-based prediction markets (Polymarket-like) with an interactive map (WorldMonitor-style). Built during an experimental sprint with AI agents, the entire MVP was delivered in 4 sprints.

**Tech stack:**
- Smart contracts: Solidity 0.8.20 + Foundry (49 tests)
- AMM: Uniswap V2–style (x*y=k, 0.3% fee)
- Frontend: Next.js 14 + MapLibre GL JS + wagmi/viem
- Backend: Next.js API routes + PostgreSQL / SQLite
- DevOps: Docker, docker-compose, GitHub Actions CI/CD
- Security: Slither audit (1 medium, 4 low findings)

**Key metrics:**
- 49 contract tests + 12 API tests — 100% PASS
- Gas: buy ~95K, createMarket ~2.17M
- Load test: 5 markets, 15 bets, flat latency

🔗 GitHub: https://github.com/mrZhigach/GeoRevolt
📜 License: AGPL-3.0

Contributions, issues, and forks welcome! Let's build the future of decentralised forecasting together. 🌍
